# Terraform AWS S3 Learning Project

This project demonstrates how to use **Terraform** to provision and manage an AWS S3 bucket using Infrastructure as Code (IaC).

## 🚀 Project Overview

In this project, I used Terraform to:

- Configure the AWS provider
- Create an Amazon S3 bucket
- Configure S3 public access blocking
- Upload an object to the S3 bucket
- Manage AWS infrastructure using Terraform
- Use Terraform state to track infrastructure
- Practice the Terraform workflow from initialization to destruction

## 🛠️ Technologies Used

- Terraform
- AWS
- Amazon S3
- Git
- GitHub
- VS Code
